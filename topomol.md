<header class="page-hero"><div class="shell page-hero-inner"><p class="index">07 / TopoMol Workbench</p><h1>Topology for<br><em>molecular trajectories.</em></h1><p>TopoMol is a local-first interface for exploring zigzag persistence on molecular structures and dynamics. It runs on your own computer through Docker.</p><a class="button" href="https://github.com/users/milap100/packages/container/package/topomol-workbench">Get the Docker image <span>↗</span></a></div></header>

<section class="page-section shell"><p class="label">Overview</p><div class="prose"><h2>A reproducible local workbench.</h2><p>TopoMol brings together molecular trajectories, zigzag persistence, barcode summaries, and representative-residue views in one interface. It is designed for exploratory, reproducible scientific work rather than a hosted analysis service.</p><p>The public Docker image runs locally. Molecular files you choose are processed on your own machine; they are not uploaded to this website.</p></div></section>

<section class="page-section shell"><p class="label">Start</p><div><h2>Run TopoMol locally</h2><ol class="records publications"><li><small>01 / Install</small><h3>Install Docker Desktop</h3><p>Install and open Docker Desktop for macOS, Windows, or Linux. No Python environment is required.</p></li><li><small>02 / Launch</small><h3>Pull and run the public image</h3><p>In a terminal, run:</p><pre class="command"><code>docker run --rm -p 8501:8501 ghcr.io/milap100/topomol-workbench:latest</code></pre></li><li><small>03 / Open</small><h3>Use the workbench in your browser</h3><p>Once the startup message appears, open <a href="http://localhost:8501">http://localhost:8501</a>. Keep the terminal window open while using TopoMol; press <code>Ctrl+C</code> there when you are finished.</p></li></ol></div></section>

<section class="page-section shell"><p class="label">Inputs &amp; outputs</p><div><h2>What it works with</h2><div class="principles"><article><span>A</span><h3>Molecular inputs</h3><p>PDB, TPR, GRO, or PSF topologies with XTC, DCD, or TRR trajectories; mdCATH-style HDF5 coordinate data is also supported.</p></article><article><span>B</span><h3>Analysis choices</h3><p>Choose atom selections, epsilon values or sweeps, stride, frame interval, homology dimension, simplex dimension, and top finite bars.</p></article><article><span>C</span><h3>Exports</h3><p>Download barcode and representative-residue tables together with JSON metadata recording the analysis parameters.</p></article></div></div></section>

<section class="page-section shell"><p class="label">Use responsibly</p><div class="prose"><h2>Interpretation and data handling.</h2><p><code>tau_top</code> is a topology descriptor derived from positive finite-bar lifetimes. It is not, by itself, a thermodynamic stability measurement. Interpret results with the molecular and experimental context in view.</p><p>For full persistence calculations on long trajectories, start with lightweight settings and scale up deliberately. Stop the container when finished to remove its temporary uploaded files.</p></div></section>
